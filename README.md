# LTK — Lion Toolkit

A modern UI component library built with Slint and Rust.

## Components

- FishButton — Primary, flat, and disabled button variants
- FishCheckBox — Toggle checkbox with label
- FishSwitch — Toggle switch with track
- FishSlider — Horizontal/vertical slider with thumb
- FishTextField — Text input with placeholder
- FishLabel — Styled text label
- TabButton / TabBar — Tab navigation
- Dialog / AboutDialog — Modal dialogs
- Toast — Auto-dismiss notification
- RoundedRect / RoundImageButton — Styled containers
- BusyIndicator — Loading spinner

## Build

```bash
cargo build
cargo run
```
